# Miss Marenda's Tea Room — Website Concept

A website design preview for **Miss Marenda's Tea Room & Upstairs Treasures**,
5 East Maple Street, Sparta, TN — homemade lunches, tea, and an antiques shop
on Sparta's historic town square.

Built with Next.js + GSAP. Photographs are the tea room's own listing and guest
photos (Google listing, Restaurantji, Wanderlog, Unearth the Voyage).

This is a design concept prepared for the business, not its official site.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Vercel project `miss-marendas-tea-room-demo`, linked to this repo (production branch).
